# DLSSNR Fixer for Cyberpunk 2077

Автоматический фикс `nvngx_dlssnr.dll` для Cyberpunk 2077 / RenoDX DLSS 5 Neural Rendering.

## Что делает

- автоматически ищет папку `Cyberpunk 2077\bin\x64` в Steam-библиотеках;
- ищет рабочий `nvngx_dlssnr.dll` на ПК;
- проверяет SHA-256;
- проверяет цифровую подпись NVIDIA;
- делает резервную копию текущей DLL;
- заменяет старую DLL только после успешной проверки новой;
- после копирования ещё раз проверяет результат;
- при ошибке пытается восстановить backup.

## Рабочий SHA-256

```text
E16BCF15E16E13F527491CDF7845B2FE6521A738D8F7C9C721866A8496E1FC8E
```

Проблемный файл, который встречался в некоторых сборках:

```text
CEB6432F6FBDF44D886014BCD47241932BF8B67439FEEF9BBDD0961436662650
```

## Как пользоваться

1. Полностью закрой Cyberpunk 2077.
2. Скачай ZIP из раздела **Releases**.
3. Распакуй ZIP в обычную папку.
4. Запусти `START_FIX.cmd`.
5. Если рабочая DLL уже есть где-то на ПК, скрипт попробует найти её сам.
6. Если не найдёт — появится окно выбора файла. Укажи рабочий `nvngx_dlssnr.dll`.
7. Скрипт проверит файл и только потом заменит DLL в Cyberpunk.
8. Запусти игру → `Home` → `Дополнения` → DLSS 5 Neural Rendering → `Reset NR feature and clear failure latch`.

## Важно

Этот репозиторий **не распространяет DLL NVIDIA**. Скрипт работает только с DLL, которая уже находится на вашем ПК или которую вы получили из легитимного источника.

Если проверка SHA-256 или цифровой подписи не проходит, файл не будет установлен.
